# Movie Ticket Booking System – Member 4

## Project Overview
This is a Java-based, terminal-driven Movie Ticket Booking System. It allows customers to select movies, choose showtimes, reserve seats, and manage their bookings.

## My Contribution
My individual contribution focuses on Seat Selection and Booking History.

## Features
- View available movies
- Select movie showtimes
- Display available seats
- Select and reserve seats
- Check seat availability
- Calculate ticket prices
- View booking history
- Cancel bookings and release seats

## Technologies Used
- Java
- Object-Oriented Programming
- Collections Framework
- Git and GitHub
- Visual Studio Code

## Project Structure

MovieBooking-Member4/

## How to Run
Open the project folder in VS Code and run:

```bash
javac src/*.java
java -cp src Main
```
